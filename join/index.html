Server beitreten

Kein Whitelist-Antrag, kein Bewerbungsformular – IP eintragen und spielen.

Server-IP — Klicken zum Kopieren

BuckSMP.de

So geht's

In 4 Schritten dabei

Wähle aus, womit du spielst.

Für Minecraft auf Windows, macOS und Linux (Java Edition).

  1. 1

    Minecraft öffnen

    Starte Minecraft: Java Edition über den Launcher – am besten mit der aktuellen Version.

  2. 2

    Mehrspieler → Server hinzufügen

    Im Hauptmenü auf „Mehrspieler“, dann „Server hinzufügen“ (oder „Direkt verbinden“).

  3. 3

    IP eintragen

    Oben auf die IP klicken zum Kopieren und als Serveradresse einfügen: BuckSMP.de

  4. 4

    Verbinden & loslegen

    Server anklicken, verbinden – fertig. Neuigkeiten gibt es im WhatsApp Channel.

Für Minecraft auf Handy, Tablet und Windows (Bedrock Edition). Hier brauchst du zusätzlich den Port.

  1. 1

    Minecraft öffnen

    Starte Minecraft auf deinem Handy, Tablet oder Windows-PC und tippe auf „Spielen“.

  2. 2

    Reiter „Server“

    Wechsle oben zum Reiter „Server“ und scrolle nach unten zu „Server hinzufügen“.

  3. 3

    Daten eintragen

    Servername: BuckSMP
    Adresse: BuckSMP.de
    Port: 19132

  4. 4

    Speichern & beitreten

    Auf „Speichern“ tippen, BuckSMP in der Liste auswählen und beitreten.

Auf Xbox, PlayStation und Switch kann man eigene Server nicht direkt eintragen. Mit einem kleinen Umweg über dein Handy klappt es trotzdem.

  1. 1

    App aufs Handy

    Lade dir die App „BedrockTogether“ auf dein Handy. Handy und Konsole müssen im selben WLAN sein.

  2. 2

    Server eintragen

    Gib in der App die Adresse BuckSMP.de und den Port 19132 ein und tippe auf „Run“.

  3. 3

    Minecraft auf der Konsole

    Öffne Minecraft, geh auf „Spielen“ und wechsle zum Reiter „Freunde“.

  4. 4

    LAN-Spiel beitreten

    BuckSMP taucht unter den LAN-Spielen auf. Auswählen, beitreten, fertig.

Probleme beim Verbinden?

Die häufigsten Stolpersteine – und wie du sie löst.

Mehr Lösungen im Hilfe-Center

„Veraltete Version“

Aktualisiere Minecraft auf die neueste Version und versuch es noch einmal.

„Verbindung fehlgeschlagen“

Prüf die Adresse: BuckSMP.de ohne Leerzeichen. Auf Bedrock muss der Port 19132 sein. Im Schul-WLAN sind Spiele oft gesperrt – probier ein anderes Netz.

Du landest im Warteraum

Der Server startet gerade neu. Bleib einfach online – du wirst automatisch zurückgeholt.

Du wurdest gebannt

Den Grund siehst du direkt auf dem Bildschirm. Wenn du denkst, dass es ein Fehler war, sprich jemanden aus dem Team an.
