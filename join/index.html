So geht's

In 4 Schritten dabei

1. Minecraft öffnen

BuckSMP läuft auf Java und unterstützt jede Konsole - egal ob PC, Xbox, PlayStation oder Switch, du kommst direkt rein.

2. Multiplayer → Server hinzufügen

Im Hauptmenü auf "Mehrspieler", dann "Server hinzufügen" (oder direkt "Server beitreten" mit der IP).

3. IP eintragen

Oben auf die IP klicken zum Kopieren, als Server-Adresse einfügen: BuckSMP.de

4. Verbinden & loslegen

Server anklicken, verbinden – fertig. Bei Fragen hilft die Community jederzeit im WhatsApp Channel weiter.
