Unter der Haube

Kleine Details, die den Unterschied machen

Vieles davon merkst du erst, wenn es darauf ankommt.

Warteraum statt Rauswurf

Stürzt ein Server ab, landest du kurz in einem Warteraum und wirst automatisch zurückgeholt, sobald er wieder läuft.

Kein Kampf-Logout

Wer mitten im Kampf das Spiel verlässt, stirbt. Ausloggen rettet dich hier nicht.

Keine Chat-Reports

Chat-Meldungen an Microsoft sind abgeschaltet. Was im Chat passiert, klärt unser Team.

Tägliche Belohnung

Mit /daily holst du dir jeden Tag eine Belohnung ab – je länger deine Serie, desto mehr Geld.

Spieler melden

Mit /report meldest du Regelverstöße direkt an das Team – die Meldung kommt sofort an.

Schlauer Chat-Filter

Beleidigungen werden erkannt – auch mit Tricks wie L3etspeak, Punkten dazwischen oder gedehnten Buchstaben.

Duelle

Streit auf dem SMP? Klärt es im Duell.

Fordere jeden Spieler im Netzwerk heraus – egal ob er gerade auf dem SMP oder in der Lobby ist. Gekämpft wird auf einem eigenen Server, mit eurem echten SMP-Inventar.

  • Echtes Risiko: Wer verliert, lässt sein ganzes Inventar in Shulker-Kisten fallen.
  • Schrumpfende Grenze: Wer nur wegrennt, macht sie schneller.
  • Faire Arena: Nach jedem Kampf wird sie komplett zurückgesetzt.
  • Zuschauen: Mit /duel watch Name bist du live dabei.

Crossplay

Java oder Bedrock? Egal.

Java-Spieler am PC und Bedrock-Spieler auf Handy, Tablet oder Konsole spielen zusammen auf demselben Server. Bedrock-Namen erkennst du am Punkt davor – so wie bei .erbse.

  • Eine Welt und dieselben Regeln für alle.
  • Keine Extra-App auf PC, Handy und Tablet nötig.
  • Konsolen kommen mit einem kleinen Umweg rein – die Anleitung zeigt dir, wie.

Zum Hilfe-Center
Wer darf auf BuckSMP spielen?

BuckSMP ist ein privater Server für Schülerinnen und Schüler vom Gymnasium Buckhorn.

Kostet BuckSMP etwas?

Nein. Wir verkaufen nichts – du brauchst nur dein eigenes Minecraft, egal ob Java oder Bedrock.

Kann ich mit Handy oder Konsole spielen?

Ja. Java und Bedrock spielen zusammen auf demselben Server. Auf Bedrock trägst du zusätzlich den Port 19132 ein. Wie es auf Konsolen klappt, steht in der Anleitung.

Welche Minecraft-Version brauche ich?

Am besten immer die aktuelle. Auf Java funktionieren aber auch viele ältere Versionen.

Was passiert, wenn der Server abstürzt?

Du fliegst nicht raus. Du landest kurz in einem Warteraum und wirst automatisch zurückgeholt, sobald der Server wieder läuft.

Wie melde ich einen Spieler?

Schreib im Spiel /report <Spieler> <Grund>. Das Team bekommt deine Meldung sofort. Einen Bug meldest du am besten direkt bei jemandem aus dem Team.
