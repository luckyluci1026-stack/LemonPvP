Was zuletzt im Admin-Panel passiert ist.

    Inhalte

    Wiki

    Artikel schreiben, sortieren und löschen. Beim Speichern werden die Wiki-Seiten sofort neu erzeugt.

    Weiterleitungen

    Alte oder andere Adressen, die automatisch zu einem Artikel führen – zum Beispiel /wiki/duell/ zu „Duelle“.

    Farbe
    Symbol
    Klick ein Minecraft-Item an. Den Namen kannst du auch eintippen, zum Beispiel diamond.

    Der Inhalt ist HTML. Die Knöpfe oben fügen fertige Bausteine ein – markierten Text packen sie gleich mit hinein. Überschriften bekommen beim Speichern automatisch einen Anker für das Inhaltsverzeichnis. Strg + S speichert.

    Inhalte

    Aura Moments

    Die Top 10 der besten Clips. Lade für jeden Platz ein Video oder Bild hoch – es erscheint sofort auf der Website.

    Seite ansehen

    Videos als MP4 (am besten H.264), höchstens 300 MB. Bilder als JPG, PNG oder WebP – sie werden automatisch in JPG umgewandelt und verkleinert. Du kannst Dateien auch einfach auf einen Platz ziehen.

    Die gespeicherten Texte konnten nicht gelesen werden. Wenn du hier Texte speicherst, werden sie komplett neu geschrieben.

    Fortgeschritten

    Code

    HTML, CSS und JavaScript der Website direkt bearbeiten. Vor jedem Speichern wird automatisch eine Sicherung angelegt.

    Ein Fehler im Code kann Seiten kaputt machen. Wenn etwas schiefgeht: Datei öffnen, unten bei „Sicherungen“ einen älteren Stand wiederherstellen. Die Wiki-Seiten fehlen hier absichtlich – die bearbeitest du im Bereich „Wiki“.

    Keine Datei geöffnet

    Wähle links eine Datei aus.

      Admin-Panel

      Einstellungen

      Code-Editor, Passwort und Wartung.

      Code-Editor

      Schaltet den Bereich „Code“ frei. Damit kannst du HTML, CSS und JavaScript der Website direkt ändern – zum Beispiel Texte auf der Startseite oder die Team-Liste. Solange er aus ist, kann auch niemand über das Admin-Panel Code verändern.

      Passwort ändern

      Mindestens 8 Zeichen. Nach dem Ändern werden alle anderen Geräte abgemeldet.

      Andere Geräte abmelden

      Beendet alle Anmeldungen außer dieser – zum Beispiel, wenn du dich an einem Schul-PC nicht abgemeldet hast.

      Wiki-Seiten neu erzeugen

      Schreibt alle Wiki-Seiten neu aus den gespeicherten Artikeln. Nur nötig, wenn Dateien im Ordner wiki/ von Hand verändert oder gelöscht wurden.
